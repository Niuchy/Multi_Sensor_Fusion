# 第三方库（thirdparty）内容说明

## 概述

`thirdparty/` 目录包含一个完整的反无人机指控系统的底层 C++ 库集合，命名为 **PXSB**（拼写反无）。核心包括 DDS 实时发布订阅通信、二进制协议序列化、坐标转换、数据库存储和并发工具。

---

## 一、PubSubTools — DDS 发布订阅

**用途**：基于 FastDDS 的实时数据分发，支持发布/订阅和请求/响应两种模式。

**核心类 `DDSer`**：

| 方法 | 说明 |
|------|------|
| `init(discovery, freq, domain, ip)` | 初始化 DDS 参与者 |
| `createWriter(topic, reliable)` | 创建话题发布者 |
| `publish(bytes, topic, level)` | 按优先级发布数据 |
| `createReader(topic, reliable, ip, port)` | 创建话题订阅者 |
| `modifyProcess(topic, callback)` | 注册数据到达回调 |
| `createClient/Server(topic)` | 创建请求/响应端点 |
| `request(bytes, topic, result, timeout)` | 同步请求-响应 |
| `getMatchedNum(topic)` | 获取匹配的订阅者数量 |

**独立函数**（`TopicAPI.h`）：
- `InitTopic()` — 初始化全局 DDS
- `createReaderUserID()` — 按用户角色订阅
- `checkTopicConfig()` / `changeTopicConfig()` — 话题配置管理
- `startDiscoveryServer()` — 启动 DDS 发现服务

**其他通信工具**：
- `UDP_send()` / `UDPServer` — UDP 直连通信
- `TianTongReceiveInit()` — 天通卫星消息接收

## 二、Common — 核心公共库

### 2.1 协议序列化 (`pxsbproto.h`)

定义了完整的二进制通信协议，包含 **90+ 种消息类型**。

**消息结构**：
```
MsgHeader (20字节) → UnitBase[] (可变)
  ├── msgID (消息类型标识)
  ├── length, timestamp
  ├── sender, receiver
  └── units → [UnitHeader(4B) + Payload]
```

**主要消息类别**：

| 类别 | 消息ID范围 | 用途 | 数量 |
|------|-----------|------|------|
| 主题管理 | 0x01xx | 话题配置/查询/变更 | 3 |
| 侦察感知 | 0x11xx-0x12xx | 目标信息、图片、视频地址 | 7 |
| 资源状态 | 0x21xx-0x25xx | 位置、运动、健康、能源、弹药 | 16 |
| 任务指挥 | 0x31xx-0x37xx | 任务收发、围栏、攻击、毁伤评估 | 18 |
| 设备控制 | 0x71xx | 模式设置、方向/指令/引导控制 | 4 |
| 设备协议 | 0x40xx-0x42xx | 无人平台连接/状态/任务/集群 | 12 |
| 仿真 | 0x91xx-0x97xx | 仿真任务/结果、移动/侦察/攻击 | 10 |
| 自定义 | 0xE0xx | 威胁匹配、人工标记、电磁态势 | 5 |

**轨迹/目标相关消息**：

| 结构体 | 字段 | 用途 |
|--------|------|------|
| `TrackPoint` | 经度、纬度、高度、时间、编号、阶段 | 单个轨迹点 |
| `DeviceTrack` | 装备ID + 轨迹点集合 | 装备完整轨迹 |
| `TargetTrackInfoMsg` (0x3403) | 任务ID、目标位置(AbsPos)、速度 | 目标跟踪报文 |
| `TargetInfo` | ID、类型、敌我、威胁、位置、速度、姿态、边界框、置信度 | 完整目标信息 |
| `TargetInfoMsg` (0x0501) | 目标信息报文 | 侦察感知 |

### 2.2 资源与目标枚举 (`pxsb_resource.h`)

| 枚举 | 内容 |
|------|------|
| `ResourceType` | 25 种装备类型（士兵、UGV、UAV、机器狗、巡飞弹、电磁装备、大疆、Go2等） |
| `TargetType` | 30+ 种目标类型（人员、地面装备、空中装备、工事、地形） |
| `TargetStatus` | 创建/更新/丢失/删除/清除 |
| `TargetIdentification` | 未知/我方/敌方/中立 |
| `TargetThreatLevel` | 低/中/高 |
| `DeviceStatus` | 正常/任务中/断连/损坏 |

### 2.3 任务模型 (`mission.h`)

| 枚举/结构 | 内容 |
|-----------|------|
| `CombatType` | 街区突击、楼宇夺控、室内清缴、协同控制 |
| `CombatUnitType` | 目标侦察、定点/区域侦察、打击、机动、搜索、监视、巡逻、建图、中继 |
| `MissionStatus` | 创建、执行中、暂停、成功、失败、取消、中止、超时 |
| `ActionStage` | 准备、机动、侦察、打击、巡逻、建图、返航 |
| `ERRMissionManager` | 900+ 错误码（按模块分类） |

### 2.4 坐标转换 (`df_coordinate_transform.h`)

`CCoordinate` 类支持以下坐标系互转：
- **RAE** (距离/方位/俯仰) — 雷达坐标
- **XYZ** (表面直角) — 本地坐标
- **JWH** (经度/纬度/高度) — 大地坐标 (WGS84)
- **XYZ** (地心直角) — 地球中心坐标

还包括速度变换和协方差传播。

## 四、桥接层

我们为 Python 调用编译了两个桥接库：

| 库 | 语言 | 大小 | API |
|-----|------|------|-----|
| `libad_dds_bridge.so` | C++ (extern "C") | 33 KB | DDS 初始化、创建Writer、发布二进制数据 |
| `libad_output.so` | 纯 C | 17 KB | UDP 初始化、发送 JSON/二进制 |

**Python 调用示例**：
```python
import ctypes
lib = ctypes.CDLL('bridge/libad_dds_bridge.so')
lib.ad_output_init(b'239.255.0.1', 0)       # 初始化 DDS
lib.ad_output_create_writer(b'radar/track', 0) # 创建话题
lib.ad_output_send_json(b'{"type":"radar"}')  # 发送数据
```

## 五、能力总结

| 能力 | 提供的库 |
|------|---------|
| DDS 实时发布订阅 | PubSubTools (FastDDS) |
| 90+ 种协议消息序列化 | common (pxsbproto) |
| 坐标系转换 (RAE/XYZ/JWH) | common (CCoordinate) |
| SQLite / RocksDB 存储 | common (SQLiteDB, RocksdbTool) |
| 线程池 + 安全队列 | common (ThreadPool, ThreadSafeQueue) |
| 优先级发布队列 | PubSubTools (MultiLevelQueue) |
| UDP 直连通信 | PubSubTools (UDPTools) |
| 卫星消息接收 | PubSubTools (TianTongAPI) |
| 配置管理 (键值对) | common (pxsb_conf) |
| 结构化日志 (spdlog) | common (pxsb_logger) |
| Python 桥接 (ctypes) | bridge (ad_output_bridge) |

这个第三方库提供了完整的**反无人机指控系统**底层基础设施：从传感器数据收集、协议封装、DDS 实时分发、到数据库持久化和任务管理。
