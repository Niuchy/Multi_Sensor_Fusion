# 反无人机数据生成系统 — 场景设计说明

## 概述

系统包含 7 个预置场景，覆盖从单目标基础验证到 15 架蜂群复杂战术的全谱系。每个场景定义无人机的数量、类型、运动轨迹、辐射源特征及传感器配置。

**坐标系**：ENU（东-北-天），原点在传感器阵地中心 (0, 0, 0)。

---

## 场景 1：单目标基础场景

**文件**：`config/scenarios/single_target.yaml`  
**时长**：90 秒  
**目标数**：1  
**用途**：基础算法验证、单传感器调试

### 目标

| ID | 标签 | 类型 | RCS | 辐射源 |
|----|------|------|-----|--------|
| 1 | DJI-Mavic3 | 四旋翼 | 0.01 m² | 2.4GHz, OFDM, 0.1W, 常开 |

### 轨迹

```
(2000, 500, 80) @ 0s    ← 2km外，高度80m
        ↓  30秒匀速飞行
(1500, 300, 80) @ 30s   ← 保持高度，直线接近
        ↓  30秒
(800,  100, 60) @ 60s   ← 降低高度
        ↓  30秒
(200,   0,  40) @ 90s   ← 抵近阵地，高度40m
```

**运动特征**：匀速直线接近，逐渐降低高度，模拟消费级无人机侦察飞行。

### 传感器配置

使用默认传感器参数，无特殊覆盖。

### 各传感器探测预期

| 传感器 | 探测情况 |
|--------|---------|
| 雷达 | 全程可探测（5000m 范围内），后期 SNR 增加 Pd 接近 100% |
| 光电 | 目标进入窄视场后才能锁定，约 30~40s 后雷达 cue 引导 |
| 电侦 | 目标全程辐射，截获概率 80%，间歇检测 |
| 声探测 | 目标进入 500m 范围后开始检测（~70s 后） |

## 场景 2：多目标复杂机动

**文件**：`config/scenarios/multi_target.yaml`  
**时长**：120 秒  
**目标数**：3  
**用途**：多目标融合算法验证、传感器协同测试

### 目标

| ID | 标签 | 类型 | RCS | 辐射源 | 机动特征 |
|----|------|------|-----|--------|---------|
| 1 | 固定翼-UAV-A | 固定翼 | 0.5 m² | 5.8GHz, BPSK, 1W, 开机 | 高速直线接近 |
| 2 | 四旋翼-UAV-B | 四旋翼 | 0.02 m² | 2.45GHz, OFDM, 0.2W, 开机 | 蛇形机动 |
| 3 | 侦察-UAV-C | 四旋翼 | 0.008 m² | 2.4GHz, OFDM, 0.05W, **关机** | 悬停+隐蔽 |

### 目标 1 轨迹（固定翼高速接近）

```
(3000, -500, 200) @ 0s     ← 3km外，右侧，高度200m
        ↓  40秒
(2000,    0, 150) @ 40s    ← 转向阵地中央
        ↓  40秒
(1000,  500, 100) @ 80s    ← 转到左侧，降低高度
        ↓  40秒
(200,   200,  50) @ 120s   ← 抵近阵地
```

**特征**：弧形接近路径（右→中→左），边下降边靠近。

### 目标 2 轨迹（四旋翼蛇形机动）

```
(500, 800, 60) @ 0s        ← 阵地右前方，中等高度
(600, 700, 60) @ 20s       ← 右移
(400, 500, 80) @ 40s       ← 左移+爬升
(300, 600, 80) @ 60s       ← 继续左移
(200, 400, 70) @ 80s       ← 下降+左移
(100, 300, 60) @ 120s      ← 终点
```

**特征**：S 形蛇形机动，高度 60~80m 间变化，模拟侦察规避。

### 目标 3 轨迹（悬停侦察）

```
(100, 100, 100) @ 0s       ← 阵地附近
(100, 100, 100) @ 60s      ← 悬停 60 秒!
(50,  100, 120) @ 120s     ← 缓慢爬升移动
```

**特征**：长时间悬停 + 电磁静默 + 极小 RCS = **最难探测目标**。

### 融合难点

| 目标 | 雷达 | 光电 | 电侦 | 声探测 |
|------|------|------|------|--------|
| 固定翼-A | ✅ 大RCS | ✅ 进入视场后 | ✅ 持续辐射 | 后期 |
| 四旋翼-B | ⚠️ 小RCS | ⚠️ 视场窄 | ✅ 间歇 | 较近时 |
| 侦察-C | ❌ 极低RCS | ⚠️ 唯一手段 | ❌ 静默 | ✅ 最近 |

## 场景 3：复杂交战场景

**文件**：`config/scenarios/complex_engagement.yaml`  
**时长**：150 秒  
**目标数**：3  
**用途**：高保真实战环境验证

### 特殊环境条件

| 条件 | 设置 | 影响 |
|------|------|------|
| 雷达干扰 | 噪声干扰 -30dBm | SNR 降低，Pd 下降，测角精度恶化 |
| 光电天气 | 能见度 5km，中等湍流 | 检测概率降低至 ~50% |
| 电侦灵敏度 | POI 降低至 60% | 截获概率大幅下降 |

### 目标

| ID | 标签 | 类型 | RCS | 辐射源 | 战术角色 |
|----|------|------|-----|--------|---------|
| 1 | 攻击-UAV-1 | 固定翼 | 0.3 m² | 6GHz, QPSK, 2W | 主攻力量 |
| 2 | 侦察-UAV-2 | 四旋翼 | 0.005 m² | 2.4GHz, OFDM, 0.1W, **关机** | 隐蔽侦察 |
| 3 | 自杀-UAV-3 | 固定翼 | 0.1 m² | 5.8GHz, CW, 0.5W | 自杀攻击 |

### 目标 1 轨迹（攻击机）

```
(4000, -1000, 300) @ 0s     ← 远处高空
(2500,  -500, 250) @ 50s    ← 接近
(1500,     0, 200) @ 100s   ← 中线
(500,    200, 100) @ 150s   ← 抵近
```

### 目标 2 轨迹（隐蔽侦察）

```
(200, 1500, 50) @ 0s        ← 阵地左侧远处
(300, 1200, 50) @ 40s       ← 缓慢接近
(400,  800, 60) @ 80s       ← 靠近
(350,  400, 70) @ 120s      ← 接近阵地
(200,  150, 80) @ 150s      ← 深入
```

**特征**：RCS 仅 0.005 m² + 电磁静默，几乎只能靠光电发现。

### 目标 3 轨迹（自杀无人机）

```
(3000, 2000, 400) @ 0s      ← 高空远处
(2000, 1500, 300) @ 30s     ← 降低高度
(800,   600, 200) @ 70s     ← 加速接近
(0,      0,  50) @ 100s     ← 撞击传感器阵地!
```

**特征**：高速俯冲，末段直冲 (0, 0) 即雷达部署点，模拟自杀式攻击。

### 融合难点

在干扰+恶劣天气+低截获概率的复合环境下，融合算法需要从零散、低质量的数据中重建完整的态势感知。

## 场景 4：饱和式突击

**文件**：`config/scenarios/swarm_saturation.yaml`  
**时长**：120 秒  
**目标数**：15  
**用途**：验证系统在密集目标环境下的处理能力

### 战术设计

```
俯视：                       侧视：
     ←  -80° (2架)          高空 300m  ○ ○ ○ ○ ○
   ←  -40° (2架)            中空 150m  ○ ○ ○ ○ ○
 ←   0°  (3架) 正面         低空  50m  ○ ○ ○ ○ ○
   ←  +40° (2架)
     ←  +80° (2架)              集中到达时间：80-110s
         ↕
      传感器阵地
```

**核心战术要素**：

| 要素 | 设计 |
|------|------|
| 突入方向 | 5 个方向，覆盖 160° 正面扇区（-80°~+80°） |
| 高度分层 | 3 层（50m / 150m / 300m），每方向每层 1 架 |
| 机型 | 全部固定翼，高速（40-60 m/s） |
| RCS | 0.05~0.3 m²，不追求隐身，靠数量突防 |
| 辐射源 | 2/3 开机，1/3 电磁静默 |
| 到达时序 | 集中在最后 30 秒（80~110s）同时抵达 |
| 组织方式 | **无领机**，分布式自主突入 |

### 战术意图

牺牲部分无人机换取整体突防成功率。15 架同时从多方向、多高度进入，防御系统需要在短时间内处理大量目标，超过目标容量则出现漏跟。

### 雷达处理压力

- 15 个目标分布在 5 个方位
- 机扫雷达每圈（6s）可更新每个目标一次
- 最后 30 秒所有目标集中进入攻击范围
- 处理能力充足（≥200 批），但数据率是瓶颈（6s/圈）

## 场景 5：侦察-干扰-打击分层协同

**文件**：`config/scenarios/swarm_layered.yaml`  
**时长**：150 秒  
**目标数**：15  
**用途**：验证多层协同杀伤链

### 战术设计

```
时间轴：
0s ───────────────────────────────────────────── 150s
│
├─ 第一层：侦察机 (5架)
│  0s 前出 ──────────────────────── 120s 抵达前沿
│  高空 300-400m, 隐身 RCS=0.01, 一半间歇辐射
│  任务：发现-识别-定位目标
│
├─ 第二层：电子战机 (4架)
│  10-30s 滞后出发 ────────────── 抵达
│  中空 150-250m, 大RCS=0.5 (外露天线), 持续大功率干扰
│  任务：压制防御系统，掩护攻击机
│
└─ 第三层：攻击机 (6架)
   50-70s 滞后出发 ─────────── 130s 冲刺
   低空 50-200m, 依赖侦察数据链
   任务：接收侦察数据 → 精确打击
```

**三层的时间-空间-功能分离**：

| 层级 | 数量 | 角色 | 高度 | RCS | 辐射特征 |
|------|------|------|------|-----|---------|
| 侦察层 | 5 | ISR | 300-400m | 0.01 (隐身) | 间歇 |
| 电战层 | 4 | EW | 150-250m | 0.5 (大) | 持续干扰 |
| 打击层 | 6 | Strike | 50-200m | 0.1-0.3 | 正常 |

### 杀伤链时序

```
T=0s     侦察层前出，电战层待命，打击层待命
T=30s    侦察层接近目标区域，开始回传情报
T=50s    电战层进入阵位，开始压制干扰
T=70s    打击层进入，接收侦察-电战协同数据
T=100s   杀伤链闭合，打击层开始冲刺
T=130s   攻击完成
```

## 场景 6：区域游荡与召唤打击

**文件**：`config/scenarios/swarm_loitering.yaml`  
**时长**：130 秒  
**目标数**：15  
**用途**：验证巡飞弹群"游荡-发现-集中"作战模式

### 战术设计

```
阶段 1 (0-70s)：分散游荡搜索
┌────────────────────────────┐
│  ○  ○    ○  ○    ○        │   15架巡飞弹
│    ○    ○  ○  ○    ○      │   5×3网格分布
│  ○    ○    ○  ○    ○      │   各绕中心盘旋(半径200-500m)
└────────────────────────────┘   高度 80-150m
        全电磁静默               被动搜索目标
              │
        发现目标 ↓
              │
阶段 2+3 (70-130s)：集中攻击
    ○ ⟍
  ○   ⟍
○     ⟶  ✖ 目标点             所有巡飞弹从各方汇聚
  ○   ⟋                       高度降低至 30m
    ○ ⟋                       辐射源开启(末制导)
```

**核心战术要素**：

| 要素 | 设计 |
|------|------|
| 机型 | 四旋翼巡飞弹，RCS 极小 (0.005-0.02 m²) |
| 游荡模式 | 各绕网格中心盘旋，覆盖 3km×3km 区域 |
| 电磁管控 | 游荡阶段**全静默**，攻击阶段开启末制导（active_after~70s） |
| 攻击方式 | 从各方汇聚到同一点，模拟同时召唤打击 |
| 高度变化 | 游荡 80-150m → 攻击末端降低至 30m |

### 探测难点

| 阶段 | 雷达 | 电侦 | 声探测 |
|------|------|------|--------|
| 游荡 (0-70s) | ⚠️ 极小RCS | ❌ 电磁静默 | ❌ 距离远 |
| 攻击 (70-130s) | ✅ 距离变近 | ✅ 末制导开机 | ✅ 进入范围 |

这是对防御系统最具挑战性的场景——大量小目标、电磁静默、突然集中攻击。

## 场景 7：分布式狼群协同搜索

**文件**：`config/scenarios/swarm_wolfpack.yaml`  
**时长**：150 秒  
**目标数**：15  
**用途**：验证分布式协同搜索与雷达覆盖

### 战术设计

```
侧翼(Y) ↑
 2000  │  ○(高) ○(高) ○(高) ○(高) ○(高)   后排 300m  — 广域监视
 1000  │  ○(中) ○(中) ○(中) ○(中) ○(中)   中排 150m  — 中距搜索
    0  │  ○(低) ○(低) ○(低) ○(低) ○(低)   前排 60m   — 前沿抵近
-1000  │  ← 间距 800-1000m →               整体推进 →
-2000  │
       └──────────────────────────────────────→ X
        -3000m   0m    3000m  搜索方向
```

**阵列配置**：

| 行列 | 数量 | 高度 | 任务 |
|------|------|------|------|
| 前排 | 5 | ~60m | 前沿抵近侦察 |
| 中排 | 5 | ~150m | 中距离搜索 |
| 后排 | 5 | ~300m | 广域监视+通信中继 |

**运动模式**：
- 整体从 X=-3000 推进到 X=+3000，覆盖 6km 纵深
- 每架走之字形（S形）搜索路径，避免盲区
- 奇偶列反相摆动，增大覆盖面积
- 高度微变模拟气流颠簸

**辐射管控**：
- 2/3 无人机开启辐射源，1/3 保持静默
- 开/关交替轮换，避免全部暴露

### 协同价值

15 架无人机形成的搜索阵面宽度约 4km，能在一次推进中覆盖大面积区域。融合算法需要同时处理 15 条航迹，并识别出其中的规律（阵列结构）以预判整体动向。

## 自定义场景

### 方法一：手写 YAML

参考 `single_target.yaml` 的格式直接编写。

### 方法二：修改生成器

编辑 `tools/generate_scenarios.py`，修改战术参数后重新生成：

```bash
python tools/generate_scenarios.py
```

### 关键参数速查

```yaml
# 无人机
targets:
  - id: 1
    label: "名称"
    type: quadcopter       # quadcopter / fixed_wing
    rcs: 0.01              # m², 越小越难被雷达发现
    emitter:
      active: true         # 电侦能否探测
      freq: 2.4e+09        # Hz, 载频
      modulation: OFDM     # OFDM/BPSK/QPSK/CW/NOISE
      active_after: 70.0   # 可选，此时间后才开机

# 仿真
simulation:
  duration: 120            # 秒
  dt: 0.05                 # 步长（保持0.05即可）
  seed: 12345              # 随机种子
```
