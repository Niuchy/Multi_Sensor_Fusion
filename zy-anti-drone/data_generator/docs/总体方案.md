# 反无人机数据生成系统 — 总体方案

## 1. 系统概述

本系统用于**模拟多传感器对无人机目标的探测过程**，生成装备结果级数据（目标轨迹信息），供融合算法使用。

系统模拟四类传感器的探测行为：雷达、光电、电侦、声探测。每个传感器按照自身物理特性独立工作，输出带有真实误差特征的检测和航迹数据。

用户可通过 YAML 配置文件定义场景（无人机数量、轨迹、传感器参数），系统运行后生成仿真数据，并提供多窗口可视化界面实时观察各传感器状态。

## 2. 场景设计

### 2.1 场景配置文件

场景文件位于 `config/scenarios/` 目录，采用 YAML 格式。每个场景定义：

| 配置项 | 说明 |
|--------|------|
| `simulation.duration` | 仿真总时长（秒） |
| `simulation.dt` | 仿真步长（秒），默认 0.05 = 20Hz |
| `simulation.seed` | 随机种子，相同种子产生相同结果 |
| `targets` | 无人机目标列表 |
| `sensors` | 传感器配置引用或覆盖 |

### 2.2 无人机目标定义

每个目标通过**航点**定义运动轨迹，系统自动在航点间平滑插值：

```yaml
targets:
  - id: 1                      # 目标编号
    label: "DJI-Mavic3"        # 标签名称
    type: "quadcopter"         # 类型：quadcopter / fixed_wing
    rcs: 0.01                  # 雷达散射截面 (m²)
    emitter:                   # 辐射源参数（电侦用）
      active: true             # 是否开机
      freq: 2.4e9              # 载频 (Hz)
      pri: 1000e-6             # 脉冲重复间隔 (s)
      pw: 10e-6                # 脉宽 (s)
      modulation: "OFDM"       # 调制类型
      power: 0.1               # 发射功率 (W)
      active_after: 70.0       # 此时间后开机（可选，秒）
    waypoints:                 # 航点列表 [x, y, z, time_offset]
      - [2000, 500, 80, 0.0]   # 起始位置，时间偏移 0s
      - [1500, 300, 80, 30.0]  # 30秒时到达此位置
      - [200, 0, 40, 90.0]     # 90秒时到达终点
```

**航点说明**：
- `x, y, z`：ENU 坐标系（东-北-天），单位米，原点在传感器阵地
- `time_offset`：从仿真开始的相对时间（秒）
- 系统在航点间使用三次样条插值，自动计算速度和加速度
- 最后一个航点之后目标停在原地

### 2.3 预置场景

| 场景文件 | 时长 | 目标数 | 描述 |
|----------|------|--------|------|
| `single_target.yaml` | 90s | 1 | 单架四旋翼从远处飞近阵地 |
| `multi_target.yaml` | 120s | 3 | 固定翼+四旋翼+悬停侦察，多目标协同 |
| `complex_engagement.yaml` | 150s | 3 | 攻击机+侦察+自杀无人机，含雷达干扰、恶劣天气 |
| `swarm_saturation.yaml` | 120s | 15 | 5方向×3高度层饱和突击，部分电磁静默 |
| `swarm_layered.yaml` | 150s | 15 | 侦察-干扰-打击三层杀伤链协同 |
| `swarm_loitering.yaml` | 130s | 15 | 巡飞弹群区域游荡→发现→集中攻击 |
| `swarm_wolfpack.yaml` | 150s | 15 | 5×3搜索阵列协同推进 |

### 2.4 生成新场景

```bash

# 然后运行生成器
python tools/generate_scenarios.py
```

## 3. 传感器模型

### 3.1 雷达

| 参数 | 值 | 说明 |
|------|-----|------|
| 类型 | Ku波段三坐标雷达 | 方位机械扫描 + 俯仰相扫 |
| 工作频率 | 16 GHz | |
| 最大探测距离 | 5000 m | Pd=85%, Pf=10⁻⁶, 目标=大疆精灵4 |
| 最小探测距离 | 200 m | |
| 方位覆盖 | 360° | 机械旋转实现 |
| 俯仰覆盖 | 0°~50° | 相扫实现 |
| 全周扫描周期 | 6 秒 | 波束宽度 3.6°，转速 60°/s |
| 距离精度 (RMS) | ≤10 m | |
| 方位精度 (RMS) | ≤0.3° | |
| 俯仰精度 (RMS) | ≤0.85° | |
| 最大测速 | 100 m/s | |
| 目标容量 | ≥200 批 | |
| 检测概率 | 85% (@5km, 精灵4) | 随距离增加而降低 |
| 虚警率 | 10⁻⁶ | |
| 输出帧率 | ~0.17 Hz/目标 | 6秒一圈，每个目标每圈更新一次 |

**工作模式**：
- **搜索模式**：360°全周扫描，6秒一圈
- **TWS 边扫边跟**：确认目标后维持全周搜索+航迹预测
- **跟踪模式**：检测到目标后，M/N 确认（2/3）→ 建立航迹

**特殊能力**：
- 可输出目标距离、方位、俯仰、径向速度（多普勒）
- 支持杂波模拟（Poisson/Weibull分布）
- 支持压制/欺骗干扰
- 引导光电传感器（发送 cue）

### 3.2 光电

| 参数 | 值 | 说明 |
|------|-----|------|
| 类型 | 光电转塔 | 可见光/红外 |
| 最大跟踪距离 | 8000 m | |
| 视场 (FOV) | ±4°(方位) × ±3°(俯仰) | 窄视场 |
| 方位精度 (RMS) | ≤0.005° | 角秒级，比雷达高60倍 |
| 俯仰精度 (RMS) | ≤0.005° | |
| 转塔转速 | 60°/s (方位) | 可快速指向 |
| 锁定时间 | 0.5 s | |
| 同时跟踪目标数 | 3 个 | |
| 检测概率 | 95% (良好天气) | 受能见度影响 |
| 输出帧率 | 30 Hz | 可见光帧率 |

**工作模式**：
- **待命** → **雷达 cue 引导** → 转塔转动 → 窄视场搜索 → 锁定 → 跟踪
- 可自主检测进入视场的目标（无雷达 cue 时）

**特殊能力**：
- **仅角度测量**，无距离信息
- 受天气/能见度影响，低能见度降低检测概率
- 高精度角度，可与雷达距离融合获得完整三维位置

### 3.3 电侦

| 参数 | 值 | 说明 |
|------|-----|------|
| 类型 | 电子侦察 | 被动辐射源探测 |
| 频率覆盖 | 100MHz ~ 18GHz | |
| 方位覆盖 | 360° | 全向 |
| 俯仰覆盖 | -10°~40° | |
| 方位精度 (RMS) | ≤1.0° | |
| 截获概率 (POI) | 80% | 取决于扫描策略 |
| 灵敏度 | -80 dBm | |
| 输出帧率 | ~1 Hz | 扫描式接收机 |

**检测条件**：
- 目标辐射源必须**开机**
- 目标频率在接收机覆盖范围内
- 信号功率高于接收机灵敏度
- 满足截获概率

**测量量**：
- 方位角、载频、PRI（脉冲重复间隔）、脉宽、调制类型

### 3.4 声探测

| 参数 | 值 | 说明 |
|------|-----|------|
| 类型 | 麦克风阵列 | 被动声学探测 |
| 最大探测距离 | ~1000 m | 小型无人机实际有效~500m |
| 方位覆盖 | 360° | 圆形阵列 |
| 俯仰覆盖 | -20°~60° | |
| 方位精度 (RMS) | ≤3.0° | 比雷达/电侦差 |
| 俯仰精度 (RMS) | ≤8.0° | 地面阵列测高精度差 |
| 频率范围 | 50Hz ~ 8kHz | 覆盖旋翼特征频率 |
| 检测概率 | 80% (@300m) | 强烈受距离和噪声影响 |
| 输出帧率 | 5 Hz | 声信号处理周期 |

**检测条件**：
- 目标在有效距离内（随距离增加 SNR 迅速降低）
- 环境噪声影响大（安静环境探测更远）
- 风速降低有效距离

**测量量**：
- 方位角、俯仰角、旋翼特征频率、声压级
- **粗略距离估计**（从声压级推算，精度~±30%）
- **无人机类型分类**（基于声纹特征）

### 3.5 四传感器对比

| | 雷达 | 光电 | 电侦 | 声探测 |
|------|------|------|------|------|
| 探测方式 | 主动 | 被动 | 被动 | 被动 |
| 最大距离 | 5000m | 8000m | 不限 | ~500m |
| 方位精度 | 0.3° | 0.005° | 1.0° | 3.0° |
| 测距 | ✅ 10m | ❌ | ❌ | ❌ (~30%) |
| 测速 | ✅ 多普勒 | ❌ | ❌ | ❌ |
| 目标识别 | ❌ | 视觉 | 辐射源识别 | 声纹分类 |
| 方位覆盖 | 360°(机扫) | ±4°窄视场 | 360° | 360° |
| 受天气影响 | 小 | 大 | 小 | 中 |
| 隐蔽性 | 暴露(主动) | 隐蔽 | 隐蔽 | 隐蔽 |
| 输出帧率 | 0.17Hz/目标 | 30Hz | ~1Hz | 5Hz |
| 引导光电 | ✅(cue) | — | ❌ | ❌ |

**融合价值**：
- 雷达：有距离有速度，精度中等 → 主力探测手段
- 光电：角度极精确，雷达 cue 后锁定 → 精跟手段
- 电侦：辐射源识别+全向预警，电磁静默目标无效
- 声探测：近距离补盲+声纹识别，适合末段

## 4. 协同工作流程

### 4.1 雷达引导光电

```
雷达360°扫描 → 发现目标 → M/N确认 → 发送cue(方位+俯仰) → 光电转塔转动
→ 窄视场搜索 → 捕获锁定 → 30Hz高精度跟踪
```

这是系统最核心的协同流程。雷达提供全局粗定位（0.3°），光电提供局部精跟踪（0.005°）。

### 4.2 四传感器协同

```
             ┌─────────┐
             │  雷  达  │ ← 主动，距离+速度+角度，全周搜索
             └────┬────┘
                  │ cue(方位+俯仰)
     ┌────────────┼────────────┐
     ▼            ▼            ▼
┌─────────┐ ┌─────────┐ ┌─────────┐
│  光  电  │ │  电  侦  │ │ 声探测  │
│ 精跟0.005°│ │ 辐射源识别│ │ 近距离补盲│
│ 窄视场   │ │ 全向预警  │ │ 声纹分类 │
└─────────┘ └─────────┘ └─────────┘
     │            │            │
     └────────────┼────────────┘
                  ▼
            ┌──────────┐
            │ 融合算法  │
            └──────────┘
```

## 5. 输出说明

### 5.1 输出方式

| 方式 | 用途 | 启动参数 |
|------|------|---------|
| 共享内存 | 进程内数据交换（GUI 显示） | 始终启用 |
| DDS 发布 | 外部融合算法消费 | `--output` 或 `-o` |
| 终端打印 | 调试查看（无 GUI 模式） | `--no-gui` |

### 5.2 DDS 输出话题

| 话题 | 内容 |
|------|------|
| `ad/radar/track` | 雷达航迹（含距离、方位、多普勒） |
| `ad/eo/track` | 光电跟踪（含高精度角度） |
| `ad/esm/track` | 电侦检测（含频率、PRI、调制类型） |
| `ad/acoustic/track` | 声探测（含声压级、分类、粗略距离） |

### 5.3 各传感器帧率汇总

| 传感器 | 配置帧率 | 有效输出帧率 | 说明 |
|--------|---------|-------------|------|
| 雷达 | 10Hz | ~0.17Hz/目标 | 机扫，6s/圈，每目标每圈一次 |
| 光电 | 30Hz | 20~30Hz | 受仿真步长(20Hz)上限限制 |
| 电侦 | 1Hz | ~1Hz | 受POI和截获策略影响 |
| 声探测 | 5Hz | ~5Hz | 近距离有效 |

## 6. 运行方式

```bash
# 激活环境
source ~/miniconda3/bin/activate anti-drone

# GUI 模式（需要显示器）
python src/main.py config/scenarios/swarm_saturation.yaml

# 无 GUI 模式（终端输出）
python src/main.py --no-gui config/scenarios/single_target.yaml

# 带 DDS 输出
python src/main.py -o config/scenarios/swarm_saturation.yaml

# 列出所有场景
python src/main.py --list-scenarios
```

## 7. 配置文件结构

```
config/
├── default.yaml          # 全局默认参数
├── scenarios/            # 场景文件
│   ├── single_target.yaml
│   ├── multi_target.yaml
│   ├── complex_engagement.yaml
│   └── swarm_*.yaml      # 蜂群场景（4个）
└── sensors/              # 传感器参数文件
    ├── radar_ku.yaml     # Ku波段雷达
    ├── radar.yaml        # 通用雷达（旧版）
    ├── eo.yaml           # 光电传感器
    ├── esm.yaml          # 电侦传感器
    └── acoustic.yaml     # 声探测传感器
```

**参数覆盖优先级**：场景 YAML 中的值 > 传感器子配置文件 > 代码默认值。
