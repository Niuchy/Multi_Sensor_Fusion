
### 1.2 分层说明

| 层 | 职责 | 关键模块 |
|----|------|---------|
| **用户接口层** | 命令行解析、GUI窗口管理、外部数据输出 | `main.py`, `viz/app.py`, `bus/dds_bridge.py` |
| **场景控制层** | 仿真时钟推进、传感器调度、数据汇聚分发 | `scenario/controller.py` |
| **真值模型** | 目标运动轨迹生成、RCS/辐射源建模 | `truth/trajectory.py`, `truth/target.py` |
| **传感器模型** | 各传感器检测逻辑、误差注入、航迹管理 | `sensors/*.py` |
| **环境效应** | 杂波、干扰、大气传播效应 | `environment/*.py` |
| **数据总线层** | 进程/网络间数据传输 | `bus/shm_pool.py`, `bus/dds_bridge.py` |

## 2. 核心设计

### 2.1 仿真主循环

```
┌─────────────────────────────────────────────┐
│              SimulationController            │
│                                             │
│  step() 每次调用推进 dt=0.05s:              │
│  ┌─────────────────────────────────────┐    │
│  │ 1. sim_time += dt                  │    │
│  │ 2. _compute_truth()   — 所有目标位置│    │
│  │ 3. _simulate_radar()  — 雷达检测   │    │
│  │ 4. _simulate_eo()     — 光电检测   │    │
│  │ 5. _simulate_esm()    — 电侦检测   │    │
│  │ 6. _simulate_acoustic() — 声探测   │    │
│  │ 7. _publish_output()  — DDS发送    │    │
│  └─────────────────────────────────────┘    │
│                                             │
│  返回 dict: {time, truth,                    │
│             radar_detections,                │
│             eo_detections,                   │
│             esm_detections,                  │
│             acoustic_detections}             │
└─────────────────────────────────────────────┘
```

**两种运行模式**：

**GUI 模式** (`SimulationRunner`):
```
QTimer(每dt秒) → _tick() → controller.step() → _update_views() → 4个窗口刷新
```

**无 GUI 模式** (`run_headless`):
```
for i in range(steps):
    result = controller.step()
    累积计数, 每2秒打印到终端
```

### 2.2 真值模型

**轨迹生成** (`truth/trajectory.py`):

```
Waypoint列表 → WaypointTrajectory
    │
    ├── 三次样条插值(CubicSpline) — 位置
    ├── 一阶导数 → 速度
    └── 二阶导数 → 加速度

get_state(t) → TrajectoryState {
    position: [x, y, z]       # 世界坐标 (m)
    velocity: [vx, vy, vz]     # 速度 (m/s)
    acceleration: [ax, ay, az]  # 加速度 (m/s²)
    heading: 水平航向角 (rad)
    speed: 水平速率 (m/s)
}
```

**运动模型** (`truth/motion_models.py`):
- `cv_model()` — 等速运动
- `ca_model()` — 等加速运动
- `ct_model()` — 协调转弯
- `hover_model()` — 悬停（随机微漂）

**目标对象** (`truth/target.py`):
```
Target {
    id, label, target_type     # 标识
    rcs                        # 平均RCS (Swerling I起伏)
    trajectory                  # 运动轨迹
    emitter {                  # 辐射源参数
        active, freq, pri, pw,
        modulation, power,
        active_after,          # 时变：此时间后开启
        active_until           # 时变：此时间后关闭
    }
}
```

### 2.3 雷达传感器

**类继承**：`RadarSensor(SensorBase)` → `sensors/radar.py`

**扫描体制**：

```
机械扫描 (scan_type="mechanical"):
    波束方位角 = (sim_time × azimuth_rate) % 360
    波束宽度 = 3.6°
    目标被照射条件: |目标方位 - 波束中心| < 波束宽度/2

凝视扫描 (scan_type="staring"):
    瞬时覆盖整个FOV
```

**检测流程**：
```
for each target:
    1. 坐标转换 → range, azimuth, elevation
    2. 距离检查 (min_range ~ max_range)
    3. 视场检查 (FOV)
    4. 机械扫描: 波束照射检查
    5. SNR = f(RCS, range) → Pd = sigmoid(SNR - threshold)
    6. 随机判定: random() < Pd ? 检测到 : 漏检
    7. 施加误差: GaussianNoise + Bias + Outlier
    8. 生成杂波: Poisson分布
```

**航迹管理** (`_update_tracks`, `_manage_scan_mode`):
```
状态机: searching → tentative → confirmed → coasting → deleted
M/N确认: 至少2次检测/3次扫描 → confirmed
coast_max=6: 连续6圈未检测 → deleted
工作模式: search → TWS(确认后) → 全周扫描+航迹预测
```

### 2.4 光电传感器

**类继承**：`ElectroOpticalSensor(SensorBase)` → `sensors/electro_optical.py`

**状态机**：
```
IDLE(待命) → SLEWING(转塔转动) → ACQUIRING(视场内搜索) → LOCKED(已锁定) → TRACKING(跟踪)

触发:
  IDLE→SLEWING: receive_cue(az, el) 接收到雷达引导
  SLEWING→ACQUIRING: 转动完成(Δaz<0.1°, Δel<0.1°)
  ACQUIRING→LOCKED: 目标在视场内且锁定计时完成
  LOCKED→TRACKING: 自动升级
  任意→IDLE: 所有目标丢失或超时
```

**引导流程**：
```
controller._simulate_eo():
    if EO状态 == idle:
        radar_tracks = 获取雷达确认航迹
        if 有确认航迹:
            计算cue方位/俯仰
            eo_sensor.receive_cue(az, el, target_id)
    
    detections = eo_sensor.detect(sim_time)  # 状态机内部推进
```

**转塔转动建模**：
```
current_az += sign(cue_az - current_az) × min(slew_rate × dt, Δaz)
转动速率: 60°/s 方位, 30°/s 俯仰
```

### 2.5 电侦传感器

**类继承**：`ESMSensor(SensorBase)` → `sensors/esm.py`

**检测条件**：
```
检测 = (
    目标辐射源开机
    AND 目标频率在频率覆盖范围内
    AND 接收功率 > 灵敏度
    AND random() < POI(截获概率)
)
```

**测量量**：方位角、载频、PRI、脉宽、调制类型

### 2.6 声探测传感器

**类继承**：`AcousticSensor(SensorBase)` → `sensors/acoustic.py`

**声学 SNR 计算**：
```
spreading_loss = 20 × log₁₀(range)     # 球面波衰减
atmospheric_loss = 0.005 × range        # 大气吸收 (~5 dB/km)
wind_loss = 0.05 × wind_speed × log₁₀(range+1)

SPL_at_sensor = SPL_1m - spreading_loss - atmospheric_loss - wind_loss
SNR = SPL_at_sensor - ambient_noise

Pd = sigmoid(SNR - 0)    # 声学检测门限 0 dB
```

**粗距离估计**：
```
range_est = 10^((SPL_1m - measured_SPL) / 20)
精度约 ±30%
```

**声纹分类**：
```
freq < 60 Hz   → "大型固定翼"
freq < 120 Hz  → "四旋翼/多旋翼"
freq ≥ 120 Hz  → "小型高速无人机"
```

### 2.7 误差模型

**误差流水线** (`sensors/error_models.py`):

```
原始测量 → [GaussianNoise] → [SystemBias] → [OutlierModel] → 输出

ErrorPipeline:
    add_stage(GaussianNoise({range: 10.0, azimuth: 0.3, ...}))
    add_stage(Bias({range: 0.0, ...}, drift_rate={range: 0.01, ...}))
    add_stage(OutlierModel(probability=0.01, scale_factor=10.0))
```

**检测概率模型** (`DetectionProbability`):
```
Pd(SNR) = sigmoid(k × (SNR - threshold))
    k 控制过渡带斜率
    threshold 为检测门限(dB)
```

### 2.8 环境效应

**杂波** (`environment/clutter.py`):
```
PoissonClutterGenerator:
    n_clutter ~ Poisson(density × volume)
    positions: 在探测空间内均匀/Weibull分布
```

**干扰** (`environment/jamming.py`):
```
压制干扰: 降低有效SNR → Pd下降
欺骗干扰: 产生虚假目标点
```

## 3. 数据流

### 3.1 内部数据流

```
Controller.step()
    │
    ├── _compute_truth() → list[dict] 直接使用
    │
    ├── _simulate_radar() → RadarSensor.detect() → list[Detection]
    │   │                                              │
    │   └── publisher.write(json) → SharedMemory(环形缓冲区)
    │
    ├── _simulate_eo() → EOSensor.detect() → list[Detection] → SharedMemory
    ├── _simulate_esm() → ESMSensor.detect() → list[Detection] → SharedMemory
    ├── _simulate_acoustic() → AcousticSensor.detect() → list[Detection] → SharedMemory
    │
    └── _publish_output() → DDSBridge.publish_raw() → DDS网络
```

### 3.2 外部数据流

```
仿真系统 → DDS Bridge (libad_dds_bridge.so) → FastDDS → 融合算法
                             │
                             └── topics: ad/{radar,eo,esm,acoustic}/track
```

### 3.3 可视化数据流

```
SimulationRunner._tick()
    │
    ├── controller.step() → result dict
    │
    └── _update_views(result)
        ├── truth_view.add_truth()           → 综合态势图 + 目标列表
        ├── radar_view.add_detection()       → 雷达 PPI + 检测点
        ├── eo_view.add_detection()+set_state() → 动态视场 + 跟踪
        ├── esm_view.add_detection()         → 方位瀑布图 + 参数表
        └── acoustic_view.add_detection()    → 方位时间图 + SPL图
```

## 5. 关键技术决策

### 5.1 仿真步长 vs 传感器帧率

- **仿真步长**：固定 0.05s (20Hz)，所有逻辑在此节拍下运行
- **传感器帧率**：通过概率模型（如机械扫描的波束位置计算）自然体现不同的有效更新率
- 雷达每步都调用 `detect()`，但机扫波束窄，大部分时刻不命中 → 有效输出 ~0.17Hz/目标

### 5.2 传感器创建策略

传感器采用**延迟创建**模式：

```python
if not hasattr(self, '_radar_sensor'):
    self._radar_sensor = self._build_radar_sensor(cfg)
```

首次调用 `step()` 时才实例化，避免 `__init__` 阶段加载过多资源。

### 5.3 配置加载机制

```
场景YAML → load_scenario()
    │
    ├── 解析 sensors.use_config → 加载子配置文件
    ├── _deep_merge(子配置, 场景覆盖值)
    ├── 展平 scenario.name, simulation 等嵌套键
    └── _dict_to_dataclass(ScenarioConfig, data)
        └── _coerce_type() — 强制类型转换 (YAML字符串→Python类型)
```

### 5.4 GUI vs 无GUI 分离

- `SimulationRunner`：GUI 模式，QTimer 驱动，调 `_update_views()` 刷新 4 个窗口
- `run_headless()`：无 GUI 模式，for 循环直接跑，终端输出统计信息
- 两种模式共用同一个 `SimulationController`，数据流完全一致

## 6. 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| 配置文件缺失 | 使用代码默认值，打印警告 |
| 传感器参数超出范围 | 自动裁剪到合理范围 |
| 共享内存创建失败 | 捕获异常，跳过该传感器发布 |
| DDS 不可用 | 优雅降级，仿真继续运行 |
| GUI 无显示器 | Qt 正常启动等待窗口（无报错） |

## 7. 扩展指南

### 添加新传感器

1. 创建 `sensors/xxx.py`，继承 `SensorBase`
2. 实现 `detect(sim_time) → list[Detection]`
3. 在 `config.py` 添加 `XxxConfig` dataclass
4. 在 `controller.py` 添加 `_simulate_xxx()` 和 `_build_xxx_sensor()`
5. 在 `viz/windows/` 添加视图窗口
6. 在 `viz/app.py` 注册窗口
7. 在 `main.py` 的 `_update_views()` 添加数据分发
8. 创建 `config/sensors/xxx.yaml`

### 添加新场景

```bash
# 方法1: 直接编写 YAML
vim config/scenarios/my_scenario.yaml

# 方法2: 修改生成器后重新生成
vim tools/generate_scenarios.py
python tools/generate_scenarios.py
```
